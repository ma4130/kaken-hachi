# でんきっこ と あそぼう

電気科のオリジナルキャラを使った、カメラで遊べる体験型作品です。

**公開URL: https://ma4130.github.io/kaken-hachi/**

## 遊び方

1. Chromeで公開URLを開き、「カメラではじめる」を押します。
2. カメラを許可し、1.5〜2m離れて上半身と両手を映します。
3. 下の動きをゆっくり試します。

| 動き | キャラの反応 |
| --- | --- |
| 上半身を左右に傾ける | 画面が傾き、キャラが滑って端につかまる |
| 両手で顔を0.5秒以上隠して開く | 近づいたキャラが驚いて跳びのく |
| 胸の前で両手を近づける・離す | 縮んだり、横に伸びたりする |
| 片腕を横にまっすぐ伸ばす | 腕の橋を手先まで歩く |
| 胸の前で腕を組む | キャラも腕を組む |

映像を左右反転して背景に表示します。カメラなしでも5枚のカードでデモを体験できます。
「もとにもどす」でデモを終了し、カメラ認識に戻ります。
本作品はカメラ映像を録画・アップロードしません。

## 開発

Node.jsで `node server.mjs` を実行し、 http://localhost:5186 を開きます。

検証: `node --check app.js` / `node --test gestures.test.mjs`

GitHub Pagesはmainブランチのルートを配信します。HTML・CSS・JavaScriptとassetsを編集してmainにpushすると更新されます。

認識はMediaPipe Pose Landmarker 0.10.32を使用します。初回にモデル・ライブラリ・フォントをインターネットから読み込みます。手首・肩・腰の位置で姿勢を推定するため、顔隠しなどは近似判定です。照明、服装、遮蔽によって認識精度が変わります。
